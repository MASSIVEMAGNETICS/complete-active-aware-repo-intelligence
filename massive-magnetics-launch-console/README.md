# Massive Magnetics Launch Console

A deployable front door for the Massive Magnetics ecosystem.

## What it does
- Gives the public one understandable entry point.
- Surfaces flagship projects first.
- Provides a searchable project database.
- Separates serious systems from experimental work.
- Gives people a clean "start here" path instead of dumping them into repo chaos.

## Stack
- Vite
- React
- TypeScript
- Plain CSS

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy
This app can be deployed directly to Vercel, Netlify, or GitHub Pages.

## Important
The included project data is structured and presentation-ready. Replace placeholder URLs with exact live repo/demo/docs links before final deployment.
